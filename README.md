## The Article I Chose

[DoorDash Uses Multi Agent LLMs to Clean up 60,000 Feature Flags](https://www.infoq.com/news/2026/09/doordash-feature-flag-cleanup/)

## My Thoughts

It's awesome to think about how much the tech landscape has changed within the last couple of years. It's crazy that we now have the capabilities to use LLM agents on a corporate level, able to assist us in dealing with smaller issues while we handle the bigger picture. I also appreciate that it's highlighted that an engineer at DoorDash would still confirm each flag before any code changes and the agents have to pass tests and static analysis before opening a PR, so it feels like a practical way to use agents at scale.
